# Ds Man — Aqua Gels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Aqua gel control (blue and grey) is drawn as a body plus a gloss layer, matching the reference push button as closely as the 3DS renderer allows, within Plan 5's frame budgets.

**Architecture:**
- A `GelClasses { body, gloss }` type replaces the class string of the six gel slots in the theme.
- `app/theme/parts/gel.tsx` renders a gel (`Gel`: the body, the gloss as its first child, then the content) and a white label with a 1 px shadow copy (`GelLabel`).
- The five parts that draw gels switch to `Gel`. A gallery state, `gels`, shows every gel state and a reference-sized pill.
- `bun run perf --check` guards the budgets, and a side-by-side image and colour table compare the pill with the reference.

**Tech Stack:** TypeScript, SolidJS via `@pocketjs/framework`, the PocketJS class compiler (`runtime/framework/compiler/tailwind.ts`), the PocketJS sim, Bun tests, Azahar (via `bun run perf`), Python 3 with Pillow (review images only).

**Spec:** `docs/superpowers/specs/2026-10-07-aqua-gels-design.md`

## Global Constraints

- **No fork changes.** Everything is in ds-man (`app/`, `tests/`, `docs/`). The `runtime` pin does not move.
- **Class literals:** every theme value is a complete class literal; the build compiles literals and cannot see concatenated strings. Gel class objects are module constants, so a slot returns the same object each call.
- **Colours (spec §3):**
  - Blue: outline `#2b4f8c`; body `from-[#4a80da] via-[#4a80da] to-[#c8daf6]`; gloss `from-[#f5f8fe] via-[#d3e1f8] to-[#93b4eb]`; label shadow `text-[#1d3f8099]` 1 px below a white label.
  - Grey: outline `#6e6e6e`; body `from-[#c4c4c4] via-[#c4c4c4] to-[#f4f4f4]`; gloss `from-[#fdfdfd] via-[#ececec] to-[#d6d6d6]`; dark labels (`#2b2b2b`) without a shadow.
- **Gloss geometry (spec §3.1), px from the body's outer edge:**

  | Gel | Gloss |
  |---|---|
  | 64 | 10, 3, 44×30, r 15 |
  | 42 | 6, 3, 30×20, r 10 |
  | 34 | 5, 3, 24×16, r 8 |
  | knob 18 | 2, 3, 14×8, r 4 |
  | badge 14 | 2, 3, 10×6, r 3 |
  | reference pill 115×44 | 9, 2, 97×18, r 9 |
  | thumb | `left-[2] top-[3] bottom-[3] w-[4] rounded-[2]`, gradients `to-r` |
  | fill | `left-[3] right-[3] top-[1] h-[4] rounded-[2]` |
  | tab | `left-[0] right-[0] top-[0] h-[9]`, square |

  Every gloss stays ≥ 0.25 px inside an outlined body's outline. Tabs and the progress fill have no outline of their own: ≥ 0.
- **Drop shadow (`shadow`):** enabled transport buttons and the seek knob only.
- **Gel bodies are `relative` (or already `absolute`),** so their absolutely placed gloss positions against them. *(Implied by the spec; the absolute children need a positioned parent.)*
- **Refinement of spec §1 (disabled gels):** a disabled transport button keeps today's 45 % opacity, its grey body and its outline. It draws **no gloss and no shadow** (gloss class `hidden`). The renderer applies opacity per primitive, with no opacity groups (`runtime/docs/DESIGN.md`, "render-to-texture opacity groups" on the punt list). A translucent gloss over a translucent body would show the body through it, and the shadow would show through the body.
- **Refinement of spec §6.2 (file names):** the `gels` state goes before `search`, because the open keyboard is modal and takes L/R, so `search` must stay last. Its captures are `8-gels-{top,bottom}@2x.png`, and `search` becomes `9-search-*`.
- **Budget (Plan 5, spec §5):** CPU work per frame in `idle`, `scroll` and `now-playing`: **≤ 14 000 µs on New, ≤ 30 000 µs on Old** (`bun run perf --check`). If a scene goes over, apply the fallbacks in this order:
  1. remove the knob's shadow;
  2. remove the shadows of prev/next and shuffle/repeat.
- **Tests:** `bun run test` (it passes `--conditions=browser`); never discover tests through `runtime/`. `dist/` stays out of Git.
- **Commits:** Conventional Commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

interface Case {

  out.push({ name: "scroll thumb", gel: AQUA.scrollThumb, tone: "blue", outline: true, shadow: false, sizes: [[11, 16], [11, 40], [11, 166]] });
  out.push({ name: "progress fill", gel: AQUA.progressFill, tone: "blue", outline: false, shadow: false, sizes: [[0, 10], [10, 10], [22, 10], [PROGRESS_TRACK_PX, 10]] });
  out.push({ name: "tab active", gel: AQUA.tab(true), tone: "blue", outline: false, shadow: false, sizes: [[40, 18], [60, 18]] });
  out.push({ name: "tab", gel: AQUA.tab(false), tone: "grey", outline: false, shadow: false, sizes: [[40, 18], [60, 18]] });
  return out;

/** A class literal's `name-[N]` value, or undefined. */
function num(cls: string, name: string): number | undefined {
  const match = new RegExp(`(?:^|\\s)${name}-\\[(-?[\\d.]+)\\]`).exec(cls);
  return match ? Number(match[1]) : undefined;
}

/** Signed distance from (px, py) to a rounded rectangle (negative inside). The radius clamps to half the shorter side, as the renderer's does. */
function sdf(px: number, py: number, x: number, y: number, w: number, h: number, r: number): number {
  const radius = Math.min(r, w / 2, h / 2);
  const qx = Math.abs(px - (x + w / 2)) - (w / 2 - radius);
  const qy = Math.abs(py - (y + h / 2)) - (h / 2 - radius);
  return Math.hypot(Math.max(qx, 0), Math.max(qy, 0)) + Math.min(Math.max(qx, qy), 0) - radius;
}

/** The gloss box for a body of width `W` and height `H`. */
function glossBox(cls: string, W: number, H: number): { x: number; y: number; w: number; h: number; r: number } {
  const left = num(cls, "left");
  const right = num(cls, "right");
  const top = num(cls, "top");
  const bottom = num(cls, "bottom");
  const x = left ?? 0;
  const y = top ?? 0;
  const w = num(cls, "w") ?? W - x - (right ?? 0);
  const h = num(cls, "h") ?? H - y - (bottom ?? 0);
  return { x, y, w, h, r: num(cls, "rounded") ?? 0 };
}

/** The least distance from any point of the gloss to the inside of the body's outline (px), or null when the gloss has no area. */
function clearance(gel: GelClasses, W: number, H: number): number | null {
  const g = glossBox(gel.gloss, W, H);
  if (g.w <= 0 || g.h <= 0) return null;
  const R = num(gel.body, "rounded") ?? 0;
  const outline = /(?:^|\s)border(?:\s|$)/.test(gel.body) ? 1 : 0;
  const step = 0.125;
  let least = Infinity;
  for (let i = 0; i * step <= g.w + 1e-9; i++) {
    for (let j = 0; j * step <= g.h + 1e-9; j++) {
      const px = g.x + i * step;
      const py = g.y + j * step;
      if (sdf(px, py, g.x, g.y, g.w, g.h, g.r) > 1e-9) continue;
      least = Math.min(least, -sdf(px, py, 0, 0, W, H, R) - outline);
    }
  }
  return least;
}

const COLOURS = {
  blue: { body: ["from-[#4a80da]", "via-[#4a80da]", "to-[#c8daf6]"], gloss: ["from-[#f5f8fe]", "via-[#d3e1f8]", "to-[#93b4eb]"], outline: "border-[#2b4f8c]" },
  grey: { body: ["from-[#c4c4c4]", "via-[#c4c4c4]", "to-[#f4f4f4]"], gloss: ["from-[#fdfdfd]", "via-[#ececec]", "to-[#d6d6d6]"], outline: "border-[#6e6e6e]" },
} as const;

test("every gloss lies inside its body, at least 0.25 px clear of an outline", () => {
  for (const c of gelCases()) {
    if (c.disabled) continue;
    const sizes = c.sizes ?? [[num(c.gel.body, "w")!, num(c.gel.body, "h")!]];
    for (const [W, H] of sizes) {
      const least = clearance(c.gel, W, H);
      if (least === null) continue; // a fill narrower than its gloss's insets draws no gloss
      expect(Number.isFinite(least), `${c.name} at ${W}×${H} has a gloss box`).toBe(true);
      expect(least, `${c.name} at ${W}×${H}`).toBeGreaterThanOrEqual(c.outline ? 0.25 : -1e-9);
    }
  }
});

test("blue and grey gels use the reference colours; a disabled button draws no gloss", () => {
  for (const c of gelCases()) {
    const colours = COLOURS[c.tone];
    for (const stop of colours.body) expect(c.gel.body, c.name).toContain(stop);
    if (c.outline) expect(c.gel.body, c.name).toContain(colours.outline);
    if (c.disabled) {
      expect(c.gel.gloss, c.name).toBe("hidden");
      expect(c.gel.body, c.name).toContain("opacity-45");
    } else {
      for (const stop of colours.gloss) expect(c.gel.gloss, c.name).toContain(stop);
      expect(c.gel.gloss, c.name).toMatch(/^absolute /);
    }
    expect(/(?:^|\s)(relative|absolute)(?:\s|$)/.test(c.gel.body), `${c.name} body is positioned`).toBe(true);
  }
  // The sideways scroll thumb runs its gradients left → right.
  expect(AQUA.scrollThumb.body).toContain("bg-gradient-to-r");
  expect(AQUA.scrollThumb.gloss).toContain("bg-gradient-to-r");
});

test("only the enabled transport buttons and the knob cast a shadow", () => {
